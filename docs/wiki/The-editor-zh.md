# 编辑器

版面沿用样板包编码器，因此你只需要学一套界面。原料在左。箭头在中间。产物在右。封包预览在下方。

有一处不同。顶部一排显示的不是储存器的格子。它显示该分组的配方。它最后一个空格用于新建配方。创建
和编辑变成同一个动作。

## 标签行

顶部一排是十列两行，共二十格。一个样板包储存器最多带二十个配方。这个上限属于样板包编码器本身。它
来自 PackagedAuto 配置中的 `pattern_slots` 项，Forge 把该项限制在 20。整合包调低该项时，上限也
随之降低。

分组一满，创建标签就会消失。终端随后会拒绝新配方，因为编码器无法再打开这样的配方。

绿框标出当前打开的标签。打开的标签角上出现红点时，表示你还没有保存。

## 数量

左键点击一个已填格子，数量面板打开。在格子上滚动滚轮同样可以改数量，按住 Shift 或 Ctrl 时步长
更大。

Keep ratio 按同一倍数缩放配方中其他所有已填格子。如果该比例无法整除每个格子，终端什么都不改，并
给出提示。不会有配方停在改到一半的状态。如果某个比例会让一个格子超过它自身的上限，终端也会拒绝。

### 合成配方每格只消耗一个物品

封包合成器的配方不会打开数量面板。这些配方类型是 Basic 到 Ultimate、Extreme、Combination、
Ender，以及普通的 Crafting 类型。

这个限制不来自本模组。工作台每格恰好消耗一个物品。PackagedAuto 在查找配方时会把数量强制改回一。
早期版本会在这些配方上打开面板，而面板什么也改不了。

## 产物格

Processing 配方由你自己写产物。

合成类配方则自行计算产物。产物格居中显示合成结果，并拒绝任何修改。下方的预览显示该配方产出的
封包。

## JEI

| 操作 | 效果 |
|---|---|
| 在 JEI 配方上按 `+` | 用正确的配方类型填满整个网格 |
| 拖动单个原料 | 填入你放下的那一格 |

两个方向都可用。`+` 按钮会选择声明该 JEI 分类的最精确配方类型，因为 PackagedAuto 的若干类型会
接受所有分类。
