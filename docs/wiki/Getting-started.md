# Getting started

## 1. Craft the terminal

One **ME Terminal** and one **Package Recipe Holder**.

## 2. Place it

The terminal is an AE2 **part**: aim at a face of an ME cable and right click. It behaves like
every other AE2 terminal, and it needs the network to be powered.

## 3. Open it

Right click the part. The screen lists every Packager, Unpackager and Packaging Provider of the
network.

Machines are **grouped by pair**. Two machines join the same group only when they carry
**exactly** the same recipes; sharing one recipe is not enough, because that used to solder
separate pairs into one line of six machines or more.

## 4. Write a recipe

1. Right click a group row. The editor opens.
2. Click the last empty tab of the top row: that is the creation tab.
3. Choose the recipe type with the arrows next to its name.
4. Fill the grid. Take an item in hand and left click a cell, or drag one out of JEI.
5. Press **Save**.

The recipe reaches the Packager **and** the Unpackager in the same gesture. PackagedAuto needs the
same recipe on both sides, and writing one side only breaks the automation silently.

## The wireless terminal

Link it in an **ME Security Terminal**, then right click with it anywhere in range. It works from
either hand, and it draws power from its own buffer.

Out of range or out of power, the screen closes rather than showing a network it can no longer
reach.

## Where to look next

Press the JEI usage key on either item for a short description page in game.
