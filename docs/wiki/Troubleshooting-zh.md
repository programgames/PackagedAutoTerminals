# 疑难解答

## 各种拒绝信息的含义

| 信息 | 含义 |
|---|---|
| **请先插入样板包储存器** | 该机器没有储存器。终端绝不会自行从仓储中取出一个：那由你决定。 |
| **该分组已满** | 已有二十个配方。这是样板包编码器的上限，不是本模组的限制。 |
| **该分组已变化** | 你的编辑器打开期间，别人改动了同一个分组。请重新打开该配方。 |
| **这个比例无法整除每个格子** | Keep ratio 已拒绝，并且**什么都没改**。绝不会留下改到一半的配方。 |
| **合成配方每格只消耗一个物品** | PackagedAuto 在合成配方上把数量强制为一。 |
| **工作未保存** | 第一次点击提醒，第二次才切换。不会悄无声息地丢失。 |
| **已应用于 2 台，1 台无储存器** | 写入成功，但分组中有一台机器没有样板包储存器。 |

## 终端自己关闭了

超出范围，或者电力耗尽。编辑器遵循同一条规则：它宁可关闭，也不显示一个它已经无法写入的配方。

## 界面放不进我的窗口

现在放得进了。两个界面在打开期间会调低游戏的 GUI 缩放，关闭时再调回来。该设置只在**内存中**改动，
你的选项文件绝不会被改写。

编辑器高 338 像素，而 Minecraft 只保证 320 乘 240。

## 两台机器本该是一个分组

只有携带**完全相同**配方的机器才会归入同一分组。共用一个配方并不够。如果一对机器裂成了两组，说明
其中一侧少了一个配方：打开任意一侧按下 Save，这次写入会同时修好两边。

## 某个配方永远不运行

打开 **Machines** 标签。如果该配方出现在孤立配方报告里，说明网络中没有对应等级的合成器。参见
[诊断](Diagnostics-zh)。

## 反馈缺陷

提交 issue 时请附上 Minecraft、Forge、AE2UEL 和 PackagedAuto 的版本、你使用的附属模组，以及可复现
的步骤。一张界面截图比一段描述更有用。
