# PackagedAuto Terminals

Ce mod ajoute deux terminaux AE2. Ils listent et modifient les recettes PackagedAuto depuis
n'importe où sur le réseau ME. Un réseau ME est le réseau d'objets d'Applied Energistics 2.

Sans ce mod, tu encodes une recette à pied. Tu remplis un Package Recipe Encoder. Tu retires le
Package Recipe Holder. Tu marches jusqu'au Packager. Puis tu marches jusqu'à l'Unpackager. Chaque
changement répète la marche. Ce mod la supprime.

## Prérequis

AE2 Unofficial Extended Life et PackagedAuto sont obligatoires. Le mod détecte tous les autres
mods par modid, et tous les autres mods sont optionnels :

- JEI, pour le transfert de recette et les pages de description.
- PackagedExCrafting et PackagedAvaritia, pour leurs propres types de recette.
- PackagingProvider, pour la machine Packaging Provider.
- AE2WUT, pour le Wireless Universal Terminal.
- AE2 Fluid Crafting avec PackagedFluidCrafting, pour les fluides. Les fluides exigent les deux.

Sans l'addon concerné, la fonction disparaît et le jeu ne plante pas.
