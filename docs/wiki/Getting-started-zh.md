# 快速上手

## 1. 合成终端

一个 **ME 终端** 加一个 **样板包储存器**。

## 2. 安装

该终端是 AE2 的**部件**：对准 ME 线缆的一个面右键点击。它与其他 AE2 终端一样，需要网络供电。

## 3. 打开

右键点击该部件。界面会列出网络中的每一台封包机、解包机和 Packaging Provider。

机器按**配对分组**。只有当两台机器携带**完全相同**的配方时，它们才属于同一分组。共用一个配方并不
够：那条旧规则曾把彼此无关的配对焊成一条六台甚至更多机器的长列。

## 4. 写一个配方

1. 右键点击一行分组，编辑器打开。
2. 点击顶部一排最后一个空标签，那是创建标签。
3. 用配方类型名旁边的箭头选择类型。
4. 填满网格。手持物品左键点击格子，或从 JEI 拖入。
5. 按下 **Save**。

同一个动作会把配方同时写入封包机**和**解包机。PackagedAuto 要求两侧配方一致，只写一侧会让自动化
悄无声息地失效。

## 无线终端

先在 **ME 安全终端**中绑定，然后在范围内任意位置右键点击。左右手都可以，它从自身的电力储备取电。

超出范围或电力耗尽时，界面会关闭，而不是显示一个已经够不到的网络。
