# PackagedAuto Terminals

本模组加入两个 AE2 终端。它们可在 ME 网络的任意位置列出并编辑 PackagedAuto 配方。ME 网络是
Applied Energistics 2 的物品网络。

没有这个模组时，你要靠走路来编码配方。你先填好样板包编码器。你取出样板包储存器。你走到封包机。
然后你走到解包机。每改一次都要重走一遍。这个模组省掉这段路。

## 前置模组

AE2 Unofficial Extended Life 和 PackagedAuto 为必需。本模组按 modid 检测其他所有模组，其他模组
全部可选：

- JEI，用于配方传输和说明页。
- PackagedExCrafting 与 PackagedAvaritia，用于它们各自的配方类型。
- PackagingProvider，用于 Packaging Provider 机器。
- AE2WUT，用于 Wireless Universal Terminal。
- AE2 Fluid Crafting 与 PackagedFluidCrafting，用于流体。流体需要两者同时存在。

缺少某个附属模组时，对应功能消失，游戏不会崩溃。
