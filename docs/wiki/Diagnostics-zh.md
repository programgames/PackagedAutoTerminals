# 诊断

## Machines 标签

它列出网络中的**封包合成器**、它们的等级，以及每一台是否正在工作。

真正有价值的是下方的报告：每一个**网络中没有任何合成器能执行**的已编码配方。

## 为什么这很重要

PackagedAuto 失败时不出声。一个为 Elite 工作台编码的配方，放在只有 Basic 的网络里，就是永远不会
运行。没有变红，没有日志，物品也不会到。这是游戏里最常见的错误，而没有其他模组会报告它。

## 读懂报告

当某个配方的类型指向网络中不存在的合成机器时，它就会被报告。

把配方类型映射到合成器类的表是**按集成分别编写**的，因为 `IRecipeType.getRepresentation()` 返回的
是合成的来源工作站，而不是封包合成器。无法识别的类型会显示为**未识别**并保持沉默，而不是给出错误
结论。

## 找到一台机器

行上的图钉按钮会在世界中标出该机器：一个染色方块和一道向上的光柱，持续十五秒。时长由配置项
`highlightSeconds` 决定。
