# 诊断

## Machines 标签

Machines 标签一打开就是报告。报告列出每一个网络中没有任何合成器能执行的已编码配方。没有其他模组
会报告这些配方。

报告下方是两节内容。Crafters 一节列出网络中的封包合成器。对每一台，它给出机器名称及其状态：未启用、
正在工作或空闲。Routers 一节列出只负责搬运封包的机器，即 Positioned Package Distributor 和
Package Crafting Machine Proxy。

## 为什么这份报告重要

PackagedAuto 失败时不出声。设想一个为 Elite 工作台编码的配方，放在只有 Basic 工作台的网络里。该
配方永远不会运行。没有变红。日志里也没有记录。物品不会到。这个错误在游戏里很常见。

## 读懂报告

当某个配方的类型指向网络中不存在的合成机器时，该标签就会报告这个配方。

我们为每个集成各写一张表。这张表把配方类型映射到合成器类。需要这张表，是因为
`IRecipeType.getRepresentation()` 返回的是合成的来源工作站，而不是封包合成器。如果某个配方类型
不在表里，该标签就不会报告它。它不会猜测。

## 找到一台机器

图钉按钮在 Patterns 标签上，不在 Machines 标签上。

1. 打开 Patterns 标签。
2. 点击某一行分组上的图钉按钮。

终端会在世界中标出该分组的所有机器。它画出一个染色方块和一道向上的光柱。标记持续十五秒，时长由
配置项 `highlightSeconds` 决定。
